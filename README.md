# 🏡 YOUPENDI IMMO SELECT

Site web professionnel pour l'agence immobilière YOUPENDI IMMO SELECT, spécialisée dans l'immobilier en République Démocratique du Congo (RDC).

## ✨ Fonctionnalités

### 🏠 **Gestion Immobilière Complète**

- **Catalogue de propriétés** - Maisons, villas, appartements, terrains
- **Recherche avancée** - Filtres par localisation, prix, type, caractéristiques
- **Géolocalisation** - Cartes interactives pour chaque propriété
- **Galeries photos** - Images haute qualité avec visites virtuelles 360°
- **Calculateur de financement** - Simulation de prêts immobiliers

### 👥 **Réseau d'Agents**

- **7 agents régionaux** - Couverture complète de la RDC
- **Spécialisations locales** - Expertise par province
- **Contact direct** - Téléphone, email, WhatsApp intégré
- **Profils détaillés** - Expérience, spécialités, historique des ventes

### 🔐 **Système d'Authentification**

- **Propriétaires** - Dashboard de gestion des biens
- **Agents** - Interface de gestion des propriétés
- **Administrateurs** - Panneau de contrôle complet
- **Sécurité** - Authentification JWT avec Supabase

### 📊 **Dashboard Propriétaires**

- **Gestion des contrats** - Baux, échéances, renouvellements
- **Suivi des paiements** - Loyers, charges, historique
- **Demandes de maintenance** - Suivi des réparations
- **Rapports financiers** - Analytics et statistiques
- **Calendrier** - Planning des visites et échéances
- **Notifications** - Alertes automatiques

### 📧 **Communication**

- **Formulaires de contact** - Demandes d'information
- **Alertes email** - Notification des nouvelles propriétés
- **WhatsApp intégré** - Contact direct avec les agents
- **Comparaison de biens** - Analyse côte à côte

## 🚀 **Installation & Déploiement**

### Développement Local

```bash
# Cloner le projet
git clone [votre-repo]
cd youpendi-immo-select

# Installer les dépendances
npm install

# Configuration
cp .env.example .env
# Éditer .env avec vos clés Supabase

# Démarrer en développement
npm run dev
```

### Production

```bash
# Construction
npm run build

# Ou utiliser les scripts fournis
./build.sh         # Linux/Mac
.\build.bat        # Windows
```

**📖 Guide complet** : Voir `DEPLOYMENT_GUIDE.md`
